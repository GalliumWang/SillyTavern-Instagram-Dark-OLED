# SillyTavern Instagram Dark OLED Theme

专为 **SillyTavern 1.19.1+** 打造的现代化纯黑暗黑 UI 主题。深度对标 **Instagram 移动端暗黑模式（OLED Pure Black）** 视觉规范，并针对 **「PC 桌面端高密度配卡 / 世界书 / 正则工程 + 移动端沉浸式长文 RP」** 的双端分工场景进行了系统级排版与交互重构。

---

## 设计理念

SillyTavern 默认暗黑主题采用偏灰的半透明毛玻璃叠层，在手机 OLED 屏幕夜间阅读时容易产生背景发灰泛白、长文纯白字眩光重影（Halation）、两侧留白过宽以及底部控件拥挤误触等痛点。

本主题遵循三大核心工程原则：

1. **真 OLED 纯黑画布与无色偏表面阶梯**：以 `#000000` 纯黑为聊天画布底座，配合 `#121212` 顶栏铬层、`#262626` 玩家发言胶囊与 `#3797EF` 标志性 Instagram 强调蓝，关闭全屏高耗电毛玻璃（`no-blur`），兼顾纯粹通透的夜间对比度与移动端满帧流畅度。
2. **长文阅读防眩光语义分层**：引入 `Inter Variable` + `HarmonyOS Sans`（鸿蒙可变黑体）`woff2` 按需分片字体与 `375` 黄金暗黑字重，将旁白叙述、人物引号台词、`*动作/心理描写*` 与楼层元数据做柔和清晰的明度与色温区分。
3. **双端响应式严格隔离**：在移动端（`<= 1000px`）释放 `92%+` 阅读屏宽并重构单手触控动线；在 PC 端（`> 1000px`）100% 保留左右图钉常驻多栏、世界书条目管理、正则脚本与预设滑块的高信息密度生产力。

## 核心特性一览

### 1. 视觉与色彩体系（Instagram Dark OLED Tokens）

| 界面层级 / 语义角色 | 色值 / Token | 视觉作用说明 |
| :--- | :--- | :--- |
| **OLED 主画布 (`--ig-bg-canvas`)** | `#000000` | 聊天流与底部输入坞纯黑底座；启用角色背景图时自动叠加纯黑暗角渐晕遮罩保障文字锐利度 |
| **主顶栏铬层 (`--ig-bg-chrome`)** | `#121212` | 顶部导航栏实色背景，并自动联动手机浏览器 `<meta name="theme-color">` 系统状态栏底色 |
| **二级扩展顶栏 (`--ig-bg-subbar`)** | `#0A0A0A` | 适配 `Extension-TopInfoBar` 等常驻顶栏扩展，微阶梯自然融入纯黑画布 |
| **玩家发言胶囊 (`user_mes_blur_tint`)** | `#262626` | 对标 Instagram DM 发送气泡，`16px` 圆角深灰胶囊承载玩家输入，与 AI 无框全宽叙事形成呼吸节奏 |
| **主标题与角色名 (`--ig-text-primary`)** | `#F9F9F9` | 角色名、激活态图标与一级标题，清脆醒目 |
| **AI 旁白正文 (`--ig-text-prose`)** | `#E2E2E6` | 适度柔化的清爽冷柔白（搭配 `375` 字重），彻底消除 `#000000` 纯黑底上的纯白刺眼散光 |
| **人物引号台词 (`--ig-text-quote`)** | `#A58C73` | 温润拿铁棕金（`420` 字重，玩家 `#262626` 胶囊内自动微提亮至 `#BC9F82`），一眼锚定人物对话 |
| **动作与心理描写 (`--ig-text-action`)** | `#9898A0` | 中性冷灰并取消中文伪斜体（`font-style: normal`），防止中文字形倾斜发虚断裂 |
| **弱化元数据 (`--ig-text-muted`)** | `#8E8E93` | 楼层号、生成耗时、Token 计数、时间戳与占位提示符，安静不抢戏 |
| **标志强调色 (`--ig-accent-blue`)** | `#3797EF` | 输入框聚焦描边、发送主按钮、滑块圆柄、选中复选框与主确认按钮 |
| **设置抽屉四级表面 (`L1 ~ L4`)** | `#0D0D0F` → `#151518` → `#1D1D21` → `#131316` | 为 `.drawer-content`、`.inline-drawer`、表头、展开区及 `#0A0A0D` 正则条目建立清晰无眩光边界 |

### 2. 中英混排护眼字体架构（1A 分片方案）

- **动态按需分片秒加载**：内置 `Inter Variable`（西文/数字可变字体）与 `HarmonyOS Sans`（鸿蒙黑体）`woff2` `unicode-range` 切片样式表。浏览器仅下载当前对话实际出现的字符分片，告别传统数十 MB 全量字体包的首屏等待。
- **暗黑防眩光字重调校**：正文默认采用 `375` 字重、行高 `1.72`（移动端 `1.75`）、字距 `0.015em` 与严格避头尾排版（`line-break: strict`），久读不累。
- **代码等宽与图标字体安全锁**：
  - 代码块（`pre` / `code`）、正则脚本编辑框（`#regex_container textarea`）与自定义 CSS 编辑框强制锁定等宽字体栈（`JetBrains Mono` / `Cascadia Code` / `Consolas`）；
  - 独立保护 FontAwesome 6 / 5 图标集（`.fa` / `.fas` / `.far` / `.fab`），杜绝全局字体替换导致的图标方块乱码；
  - 对酒馆助手 / 前端 HTML 渲染卡片（`.TH-render` / `.mes_text iframe`）启用跨帧暗黑透明合成保护，消除 iframe 四角白边漏底，且绝不强行污染卡片内部自定义排版色。

### 3. 双端响应式隔离优化

#### 移动端沉浸 RP 体验（`@media screen and (max-width: 1000px)`）

- **全宽沉浸正文**：移除 `#chat` 左右侧边框、`11px` 固定滚动条槽与 `.mes_text` 右侧 `30px` 历史留白，释放 `92%+` 屏幕横向有效阅读宽度，正文自动放大至 `1.08` 倍舒适阅读字号。
- **微缩头像与左下角状态横条**：将角色头像精简为左上角微缩圆头像（`28×28px`），左下角流式排列 `#楼层 · 耗时 · Token数` 单行弱化信息栏；当开关全关或内容为空时自动坍缩为 `0px`，不留空白断层。
- **大触控热区 Swipe 切分支**：最新消息底部的 `<` 与 `>` 升级为 `44×44px` 防误触暗黑圆钮，分支计数胶囊化为 `1/2` 标签并与左下指标同轴避让；单分支无计数文本时自动隐藏空胶囊框；非最新楼层右上角操作图标自动降噪至低透明度防误触。
- **Instagram DM 风格底部输入坞**：
  - Quick Reply 快捷回复栏（`#qr--bar`）强制收拢为**单行横向丝滑滑动描边芯片轨道**，不再折行挤占半屏聊天视野；
  - 输入框重塑为 `#000000` 纯黑圆角胶囊（`22px` 圆角，聚焦平滑过渡至 `#121212` 底 + `#3797EF` 蓝框，字号锁定 `15px+` 防止移动端无故缩放），右侧搭配 `#3797EF` 实心正圆发送键；
  - 完整适配全面屏与 iOS Safari 底部 Home 横条安全区（`env(safe-area-inset-bottom)`），顶层抽屉开启时锁定 `overscroll-behavior: contain` 防止背景滚动穿透；同时针对嵌套在 `#WorldInfo` 内的世界书面板（`#world_popup`）专门解除内层滚动链死锁与多余套娃边框，确保手机端世界书长列表上下触控丝滑滚动且右侧条目操作按钮完整露出。

#### PC 桌面端生产力保护（`@media screen and (min-width: 1001px)`）

- **零阉割高密度工作台**：完整保留左右两侧抽屉图钉（Pin）常驻并排布局、全部顶栏扩展入口与消息操作按钮。
- **表单与滑块细节打磨**：重构全站 Select2 多选/单选组件（如全局世界书选择器与角色标签栏），消除内联搜索框双重套框与汉字下沿裁切，美化已选标签胶囊与下拉勾选高亮；拓宽预设面板 `.neo-range-input` 数值输入框（`min-width: 92px` + `tabular-nums` 等宽数字对齐），确保 `2000000` 等百万级上下文数值完整显示不切边；优化玩家胶囊与右侧 Swipe 箭头的安全间距，且对各类第三方悬浮球/宠物/状态栏扩展保持零干扰。

## 安装、更新与无损回滚指南

### 1. 首次安装（一键导入）

1. 打开 SillyTavern，点击顶部栏的 **用户设置（User Settings，齿轮/滑块图标）**。
2. 在左侧 **UI Theme（界面主题）** 区域点击 **Import Theme（导入主题 / 文件夹上传图标）**，选择本仓库的 `Instagram-Dark-OLED.json`。
3. 若弹出外部样式确认提示（询问是否允许加载 `@import` 在线字体样式），点击 **确认 / Yes** 即可立即生效。

> **原生引号高亮检查**：本主题直接利用 SillyTavern 原生 `<q>` 标签为中英文引号台词上色。请确认用户设置中未关闭引号自动高亮格式化；导入主题时会自动启用单条消息 Token 计数显示（`message_token_count_enabled`）。

### 2. 版本更新提示

SillyTavern 原生导入逻辑不支持同名主题直接覆盖。升级新版 `Instagram-Dark-OLED.json` 前：

1. 先在 `UI Theme` 下拉框中选中旧版 **`Instagram Dark OLED`**；
2. 点击旁边的 **删除按钮（垃圾桶图标）** 确认移除旧条目；
3. 再次点击 **Import Theme** 导入新版 `.json` 文件即可。

### 3. 历史消息 Token 计数补齐技巧

导入主题后，新生成的消息会自动在左下角（移动端）或消息头部（PC 端）显示 Token 数。若希望旧存档中的历史楼层也一并显示 Token 计数，可在用户设置面板中点击 **`Backfill token counters`**（或在输入框执行相应回填命令）一键计算补齐。

### 4. 一秒无损回滚

本主题为纯前端视觉层配置，**不会修改任何角色卡、世界书、预设或聊天记录文件**。如需恢复默认外观，只需在 `UI Theme` 下拉菜单中切回任意内置主题即可瞬间还原。

## 常用自定义微调速查

所有样式均集中在用户设置的 **`Custom CSS`** 文本框（与 `instagram-dark-custom.css` 完全对应），可按个人喜好随时微调：

- **修改人物台词引号颜色**：
  直接在用户设置面板中点击 **`Quote Text`** 色块取色，或在 `:root` 中修改 `--ig-text-quote: #A58C73;`（例如改为冷调冰雾蓝 `#D6EAFF` 或明亮暖白 `#F5EFE6`）。
- **调整移动端正文字号倍率**：
  搜索 `#chat .mes .mes_text`，修改 `@media screen and (max-width: 1000px)` 下的倍率系数：
  ```css
  #chat .mes .mes_text {
      font-size: calc(var(--mainFontSize) * 1.08); /* 可按喜好改为 1.05 ~ 1.15 */
  }
  ```
- **纯离线环境使用系统原生字体**：
  若处于无外网离线环境，直接删除或注释 `Custom CSS` 顶部的两行 `@import url(...)`，字体栈将自动无缝回退至本机 `PingFang SC` / `HarmonyOS Sans` / `Microsoft YaHei UI`。
- **调节 PC 端聊天阅读列宽**：
  本主题在桌面端不硬编码锁死 `#sheld` 宽度，你可直接通过 SillyTavern 用户设置中的 **`Chat Width`（聊天宽度滑块）** 自由调节最顺眼的分栏比例。
